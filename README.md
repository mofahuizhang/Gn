## 这是什么

**Gn是一套以中医病机分析为内核、可跨域迁移的通用分析框架。**

它不是"用中医比喻AI"的通俗科普，而是一套**有独立公理公设、有四层主坐标、有三学框架、有病机分类、有辨证推演、有验证边界**的完整理论体系。从中医内核出发，Gn已经完成了三个方向的深度展开：

1. **医学体系**（v6.21）：将中医理论现代化、结构化，覆盖肿瘤、气血动态诊疗、跨传统医学映射、中医流派消化、三阴三阳随文释义等专题
2. **大模型篇**（v2.17）：将病机分析方法系统映射到AI产业30个核心难题，对应20方36说药典卷
3. **行业推演**（v1）：以中医药行业25项核心问题为对象，分五专题进行结构化回应与验证边界界定

> Gn的G层概念源自nACGD的ACGD八维认知闭环中的G（知识图谱层），但已发展为独立的病机分析体系，拥有自己的A0三才耦合公理、A1物质-功能耦合公设、A2四层主坐标最优性。

## 为什么这个框架重要

### 1. 跨学科原创性：中医病机×现代系统科学，前无古人

Gn的核心创新在于：将中医两千年来积累的病机分析体系、辨证论治方法论和历代验方库，用现代系统科学的语言（公理、公设、坐标、信道、反馈闭环）重新表述，使其成为**可记录、可推演、可验证、可跨域迁移**的通用分析框架。

这不是简单的"中医现代化"，而是**从中医内核中提炼出一套通用的复杂系统分析方法**——这套方法不仅能分析人体疾病，也能分析AI模型失效、产业问题、组织病理。

### 2. 公理体系严谨：A0-A2三公理+四层主坐标

Gn不是零散的观点集合，而是有严格公理基础的理论体系：

| 公理/公设 | 内容 | 作用 |
|---|---|---|
| **A0 三才耦合公理** | 人体与环境之间持续的物质、能量和信息交换 | 为"天人耦合"、环境因素与系统状态接口提供总框架 |
| **A1 物质—功能耦合公设** | 物质结构与功能活动放在同一关系中考察；E↔Q偏重运行层面，X↔Y偏重存在与功能层面 | 形神映射的工程化实现 |
| **A2 四层主坐标最优性** | 以L1-L4作为开放复杂系统的全局主坐标；各层可以继续用Ln.x细分 | 证明主坐标数k=4为最优，不把"四层"误解为分辨率上限 |

### 3. 三学框架：病-养-变，完整覆盖复杂系统生命周期

| 学 | 中医对应 | 通用含义 | 核心内容 |
|---|---|---|---|
| **病理学** | 疾病的病因、病机、分类 | 系统失效分类与故障诊断 | 失效分类体系 + 可回滚边界判定（四问决策树 + 回滚恢复率R(t₀)） |
| **养育学** | 小儿养育、调护、变蒸 | 系统训练、调优、能力发育 | 17子节——变蒸/三原则/八法/望诊/分化/审计等 |
| **跃迁学** | 疾病传变、体质质变 | 系统架构质变、能力跃迁 | P_max抬升 + 架构质变 + scaling law残差/E_eff跳变/迁移率T + 案例库 |

### 4. 双域深度应用：医学+AI，各有完整体系

Gn不是只在一个领域做浅尝辄止的应用，而是在**医学和AI两个领域都做了深度展开**：

- **医学体系 v6.5**（160KB主文档+肿瘤篇62KB+3个附录59KB+汇总13KB）：完整的中医现代化体系
- **大模型篇 v2.17**（250KB）：AI产业30题病机分析+20方36说药典卷+ABAF机制迁移7机制

### 5. 验证边界清晰：不把"能够描述"写成"已经解决"

Gn框架有严格的方法论纪律——所有结论均区分三个层面：

1. **结构层**：问题能否被Gn的层级、信道、Maod、偏性向量或反馈闭环描述
2. **推演层**：是否能够形成相对完整的机制链、干预路径或产品接口
3. **验证层**：是否已有真实数据、外部复核、临床试验、工程部署或政策采纳

并使用四级回应等级（框架回应较完整/框架已建立/提供间接支撑/暂不作判断），**不把理论上的"能够描述"直接写成"已经解决"**。

## 核心概念

### A0 三才耦合公理

人体（或任何开放复杂系统）与环境之间持续进行物质、能量和信息交换。这是"天人耦合"、环境因素与系统状态接口的总框架。

### A1 物质—功能耦合公设

将物质结构与功能活动放在同一关系中考察：
- **E↔Q**：偏重运行层面（能量-质量耦合）
- **X↔Y**：偏重存在与功能层面（结构-功能耦合）

在AI领域，这一公设表现为**M-F耦合**：模型层（M）与反馈层（F）的动态耦合，是AI系统形神映射的工程化实现。

### A2 四层主坐标最优性

以L1-L4作为开放复杂系统的全局主坐标，各层可以继续用Ln.x细分。v2.16提出了主坐标数k=4为最优的论证。

| 坐标层 | 医学对应 | AI对应 |
|---|---|---|
| L1 | 屏障/界面 | 模型层（架构、参数、能力） |
| L2 | 层间节点 | 反馈层（数据、训练、评测） |
| L3 | 脏腑功能 | 耦合层（训练动态、能力发育、跃迁） |
| L4 | 整体储备 | 生态层（产品、产业、监管、伦理） |

### Maod 矛盾度

描述系统状态相对于稳态基线的偏离程度。当前阈值属于框架级估算，需数据校准。

### 四维偏性向量 V

以相容度、功能调控方向、作用模式和作用层级描述干预手段，不替代药理、药代和安全性评价。

### 三类全域信道

区分层外信道、层间信道和层内信道，用于描述环境输入、跨层传导和局部协同。

## 理论渊源与家族

Gn不是孤立的理论，而是作者整个理论家族的一部分：

| 框架 | 定位 | 与Gn的关系 |
|---|---|---|
| **nACGD** | 层级化通用认知框架 | Gn的G层概念源自nACGD的ACGD八维认知闭环中的G（知识图谱层） |
| **TFT** | 信任截断分析框架 | 共享注意力稀缺理论根基 |
| **LBAF** | 损益分析框架 | 共享多主体损益核算方法，Gn的账户机制源自LBAF |
| **SUI** | 语义寻址语言 | Gn的坐标系设计与SUI的语义寻址有方法论共鸣 |
| **SCION** | 提示词寻址篇 | Gn的养育学涉及提示词工程与模型调优 |
| **ABAF** | 对偶面分析框架 | Gn从中迁移了7个核心机制（对偶面/账户/德位配/层累链/参照线/动力学/评估姿态） |

这些框架共享同一套理论基因（注意力稀缺公设），形成了一个**可互相印证、可交叉迁移的理论家族**。
