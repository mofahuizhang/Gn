## 一、CSMT 的「矩阵」实为何物（一手材料）

材料源：`…\P1_同源三框架\发布版\CSMT-认知语义基元矩阵论-定义层.md`、`…-总卷.md`、`同源三框架-导航卷.md`。

### 1.1 「矩阵」一词在 CSMT 中有三重所指

| 所指 | 出处 | 义 |
|---|---|---|
| $\sigma_{3\times3}$ 耦合矩阵 | P2 公设 | 三码（语义／语形／语音）互锁的耦合关系 |
| **语义晶格** | **D2 义原矩阵（本件所取）** | 义原在语义空间中的结构化分布 |
| 公共矩阵 | P3 公设／D16-D18 | 知识块注入后形成的文明公共语义承载 |

**D2 明言**：「"矩阵"一词在此指三重结构……D2 所指的矩阵是语义晶格——义原在语义空间中的结构化分布。」故用户所谓「矩阵」，正是此**语义晶格**一义，非耦合矩阵、非公共矩阵。

### 1.2 D2 义原矩阵：两个特征

- **族聚性**：义原按语义相近性聚为**八族** $\{F_1,\dots,F_8\}$，族内联系紧密、族间相对疏离。**八族不是人为划分，而是分布中自然涌现的聚类结构。**
- **正态性**：义原在各语义维度上的分布近似正态——多数居中央，少数在边缘。

**形式化**：$\mathbf{M}: S\times\mathcal{V}\to\mathbb{R}^+$，八族满足 $\bigcup_{i=1}^{8}F_i=S$，且**族内语义距离显著小于族间**。

> **诚实边界**：CSMT 现行六卷中**未见八个族的集中名录**（八族只以 $F_1\dots F_8$ 记；扩展层 H-9 提及其中含「事实族」「情绪族」两种，且注明二者边界不够清晰、保留为假设）。故此处只取其**结构**（族聚＋族内紧族间疏），不取其**名录**。

### 1.3 族间有「周期性」，缺陷可探测

三论定理层 **T5（晶格缺陷预测定理）**：「正常格结构中，族间关系遵循**周期性模式**——类似于化学元素周期表中族间关系的周期性。若格结构在某处偏离周期性模式，该处存在『晶格缺陷』——义原组合的逻辑断裂或缺失。」

此点对 Gn 有直接启发：**族之划分不是为了归类好看，而是为了能看出"缺位"**——某处该有的概念没有，即为体系之缺陷（Gn 侧对应物：待建位／待核，见《AGENTS.md》）。

### 1.4 「纵」由 D6 承担：语义偏序与义原格

**D6 语义偏序与义原格**：「义原间存在逻辑蕴涵关系构成偏序集；义原空间在该偏序下形成格结构——**Core 子集为分配格，全域为 Heyting 格**。」

- 偏序定义：$s_i\le s_j$ 当且仅当 $s_i$ 蕴涵 $s_j$（语义包含）。例：「**人类**」$\le$「**生物**」$\le$「**存在**」。
- Core 子集满足分配律（$a\wedge(b\vee c)=(a\wedge b)\vee(a\wedge c)$），为**分配格**；全域含 Peripheral，引入时变后不再满足分配律，退为 **Heyting 格**（伪补运算 $\Rightarrow$）。

### 1.5 量级：为何「凑不起来」

**D1**：Core≈**200** 个（封闭不变）＋ Peripheral≈**59** 个（随文明演化可变），总量 **259**。

CSMT 面对 259 个义原，**并不逐一配对**——而是（横）归类入八族、（纵）纳入偏序格。这正回答了用户的疑虑：**矩阵不是"对子表"，是"族聚＋偏序"两轴的组织方式。**

### 1.6 相关：D29 语义层累链（Gn 已有实例）

D29：概念在历史演化中形成的**纵向语义堆栈**（层累，非派生），各层语义共存、由语境指针 $\phi$ 寻址激活。Gn 侧《附录E_体质阴刻》之**阴阳层累链**即与 D29 同构，已是现成落点。

## 二、CSMT 之「格」即概念学之「上位下位」

D6 之蕴涵偏序（「人类」$\le$「生物」$\le$「存在」），在概念学中即**属种关系**。「$s_i$ 蕴涵 $s_j$、$s_i$ 的语义包含于 $s_j$」——这正是「**下位概念**包含于**上位概念**」。

两条线在此**独立收敛**：**CSMT（数理侧，D6 偏序格）** 与 **概念学（术语标准侧，属种关系）** 说的是同一件事。故 Gn 组概念体系，可同时取两侧之形：CSMT 给「偏序」之数学直觉，概念学给「上位／下位／并列」之命名与规约。

## 三、概念学的「概念体系」（标准材料）

来源：**GB/T 10112—2019 / ISO 704:2009《术语工作 原则与方法》**、**GB/T 20001.1—2001《标准编写规则 第1部分：术语》**、GB/T 10112—1999 旧版。

### 3.1 层级关系只有两型

GB/T 10112—2019 §2.1 明列**层级关系的类型**：
- **a) 属种关系**；
- **b) 整体-部分关系**。

[@GB/T 10112—2019/ISO 704:2009](https://wx12345.gzonline.gov.cn/fastuser%2FM00%2FE2%2F72%2FCsL9JGcKGjGAVJRpAT4VzW_sJs0982.pdf)

对应的**概念体系类型**亦有属种概念体系：「在一个体系中，所有的概念相互都呈现属种关系，则该体系被认为是**属种概念体系**。」

### 3.2 上位／下位／并列

- **上位概念（superordinate concept）**：层级系统中，可划分为若干个下一级概念的概念。
- **下位概念（subordinate concept）**：层级系统中，可与一个上位概念相对应被划分出来的概念。
- **并列概念**：「按**同一标准（同一维度）划分**并处于**同一层面**的概念」。

[@GB/T 20001.1—2001](http://www.gdzjsc.com/Public/stdPDF/GB!T%2020001.1-2001.pdf)
[@术语工作 原则与方法·3.3.1](http://www.jss.hit.edu.cn/hitss/pub/biaozhunguifan/shuyuyuanze.htm)

### 3.3 整体-部分关系

「整体-部分关系指**客体间的包含关系**。小概念对应的客体是大概念对应的客体的**组成部分**。」
[@术语工作 原则与方法·3.3.1.2](http://www.jss.hit.edu.cn/hitss/pub/biaozhunguifan/shuyuyuanze.htm)

> Gn 侧现成例：**三才 ＞ 天／地／人**（整体-部分）；**脏腑 ＞ 五脏＋六腑**（整体-部分）；此与「五脏 ＞ 心／肝／脾／肺／肾」之属种关系**不同型**，须在表中分列，不可混。

### 3.4 定义的优选结构

GB/T 20001.1—2001 §5：「定义的优选结构是：**定义＝上位概念＋用于区分所定义的概念同其他并列概念间的区别特征**。」

> 此条对 Gn 有约束力：凡字典条目，宜先指其**上位**（族／宗），再给**区别特征**。现《Gn 术语字典 v1.8》多为「精确定义＋出处」两栏，未标上位——此为可回填之处。

### 3.5 非层级关系（「相邻相近」之落点）

层级关系之外，概念间尚有**非层级关系**：序列关系、因果关系、空间关系、时间关系等。**「相邻相近」即此**——同一族内、同一维度上位置相邻的两个概念（如**六经传变序** 太阳→阳明→少阳→太阴→少阴→厥阴，为**序列关系**，非属种、非整体-部分）。

### 3.6 可选数学工具：形式概念分析（FCA）

FCA 以**形式背景** $K=(G,M,I)$ 构造**概念格** $L(G,M,I)$（完备格），用于挖掘概念层次关系。

> **建议**：Gn 是**医学概念体系**，不必引入格论数学形式。按取词纪律「**代结可用、代造不可用**」，只取「**偏序**（上位下位可溯）」之直觉，**不引入格论术语**（分配格／Heyting 格／伪补等概不借）。FCA 仅作背景知识登记，不入 Gn 件。

### 3.7 两张网合起来才是「概念体系」

- **纵网（层级）**：属种关系 ＋ 整体-部分关系；
- **横网（同层与非层级）**：并列（同维度同层面） ＋ 相邻／序列（非层级）。

**纵网定"谁在谁下"，横网定"谁与谁同级、谁挨着谁"。** 二者交叉成网，方为「概念体系」。

## 五、方案：Gn 概念体系之三轴（族／序／辨异）

对齐 CSMT（**横之族聚 ＋ 纵之偏序**）与概念学（**层级两型 ＋ 并列 ＋ 非层级序列**），Gn 概念体系立**三轴**：

### 5.1 横轴·族（相近相邻者聚族）

把 Gn 概念按「相近相邻」归族。**族之划分标准三选**（待裁）：
- **甲 学说域**：阴阳／五行／脏腑／经络／气血津液／病机／治则／方药……
- **乙 M-F 投影**：承 D2.1 之对偶族（阴阳＞气血／精气／营卫／津液；形神＞魂魄）；
- **丙 L1-L4 层位**：按层归族。

> **推荐**：以**学说域**为第一级族（好认、好增补），M-F 投影与 L 层位**降为族内之坐标标注**（每概念标 $V=[\beta,\gamma,\delta,L]$ 与 M／F 侧），不另立第二套族。

### 5.2 纵轴·序（上位下位者成序）

立**三类关系**（依概念学层级两型 ＋ 非层级序列）：

| 关系型 | 概念学对应 | Gn 例 |
|---|---|---|
| **属种**（上位⊃下位） | 属种关系 | 病机 ＞ 虚实 ＞ 虚 ＞ 气虚／血虚／阴虚／阳虚 |
| **整体-部分** | 整体-部分关系 | 三才 ＞ 天／地／人；脏腑 ＞ 五脏 ＋ 六腑 |
| **序列／相邻** | 非层级关系（序列） | 六经传变：太阳→阳明→少阳→太阴→少阴→厥阴 |

三条各**列一栏**，**不得混**（属种与整体-部分虽同称"层级"，概念学明分两型）。

### 5.3 辨异（同名／近义／已废）

借 QA-GPS 4.7 定义段步三之**辨异三型**（只借其**形**，不搬其「原语对」入口）：
- **甲·同名异义**——Gn 已有素材：字典 §五（D₂ 三指代）、§九（MCAF／UCAF 之 A1/A2/A3、γ）；
- **乙·近义须分**——Gn 待建：如「虚」与「亏」、与「损」；「闭」与「堵」与「塞」（可对《附录7_堵与毒篇》）；
- **丙·已废已撤**——Gn 已有素材：L1-L4 **旧名退役**（屏障界面层／半表半里中观层／脏腑功能层／元神元气层）。

### 5.4 字典＝竖读，矩阵＝横读

**同一底表两个读法**（合 QA-GPS 4.7「步三＝步四同表两读」之要）：
- **横读＝矩阵**：按族聚看拓扑、看并列、看缺位；
- **竖读＝字典**：《Gn 术语字典》按条目给定义。

底表只维护一份，**不重复维护**。若裁定升位，则字典 v1.8 之条目即底表之竖读面，加**上位**一栏（合 §3.4 定义优选结构）即成。
