## 一、全链：产物序 ＋ 三条贯穿线

**产物序（生成方向）**——三个产物、三处材料锚点：

```text
    Q 问题态 ──────────→ P 象 ──────────→ A 策
      ↑首份材料              ↑分析材料         ↑反应材料
```

**贯穿线（三条，均不占步骤位）**——贯穿上述全序：

```text
    S 采集 ──────────────┴───────────────┴──── 全程三形态（首份／分析／反应）
    G 知识 ──── 比类基准 ──→ 指南规范／价目表     （P 侧比类基准；O 侧指南规范·价目表）
    O 选择 ──── 约束下可行集产生（落 O₁／O₂／O₃）   （双动作：产生候选 → 有限理性选择 → 策）
```

**入出相争**——S（写入／采集新材料）与 G 的调用（上浮／调用既有知识）**争同一份预算**：`ABGK G-X-1` 入出同池相争律（**零和·须协调**；协调＝**学用相咬合**，`G-X-2` 沉积-上浮协调律）——**§2.5 已立**。

| 层 | 元素 | 占位 | 产物／作用 | 口径出处 |
|---|---|---|---|---|
| **产物序** | **Q** | 第一层 | 完整求助结构——首份材料随之入场 | QA-GPS §0.0／R10 |
| | **P** | 第二层 | 象——分析材料（取象所需）随之入场；同一象两体系表述 | 辨证论治篇 卷四 §4.1／§4.8 |
| | **A** | 第三层 | 策——反应材料（施治之后）随之入场 | 卷四 §4.1 |
| **贯穿线** | **S 采集** | 不占位 | 四诊合参＋化验单／影像；三形态贯穿全程 | 辨证论治篇 卷一 §1.1 |
| | **G 知识** | 不占位 | P 侧比类基准；O 侧指南规范·价目表 | QA-GPS R9 双支持 |
| | **O 选择** | 不占位 | 约束下可行集之产生；落 O₁／O₂／O₃ | QA-GPS §0.0·§2.4 |
| | 审核 | 归 O 线 | 审计→核验→裁决；**裁决＝O₃，不可代行** | QA-GPS §8.5 |

**材料锚点（与产物对应）**：**首份材料**（呈现问题——随 Q 入场）→ **分析材料**（取象所需——随 P）→ **反应材料**（施治之后——随 A；其入场即开启 Q′）。

**O 之双动作**（Option）：**①产生候选**——约束下产生**选项集**（世谓「谋士上中下三策」者即此）；**②有限理性选择**——择一，得**策**（措施向量）。故 O **贯穿 P 与 A**：P 之成形里有 O 的过程（**OP 选择对**），A 之成形里亦有 O 的过程。三落点：**O₁ 授权决策／O₂ 执行决策／O₃ 价值责任决策**（历史名 D₁／D₂／D₃）；**两链分立**——授权链（O₁ 分层授权·可撤销）与责任链（O₃ 不可代行）。

**迭代**：施治后**反应材料**入场 → **Q′ → P′ → A′**（自然驱动，不依赖反思件）。

**与旧三联之差异（须在升级稿里说清）**：S／G／O **皆不占步骤位**（原把 S 与审核当步骤，是**节点读法**之误——二者实为**贯穿线**）；P 是**产物名**（取象＝过程名）；**策改记 A**（结果层），而 **O 降为「贯穿 P 与 A」的约束选择动作**；补入旧稿所无的 **Q₀ 完整求助结构／Qₙ 收敛**、**G 知识底座（PO 双支持）**、**审核三重门**三层，以及**入出相争**（S 写入 与 G 调用 同池争预算）。

## 二、「象」的写法：三元

本体系之象 ＝ **体质阴刻** ＋ **Ln 定位** ＋ **矛盾度定性**。三元各有所指、各有所本：

| 元 | 写什么 | 本体系之据 | 例（示意） |
|---|---|---|---|
| **体质阴刻** | 此人的**慢轴规格**——四个凹槽（L1／L2／L3／L4）之基线配置 | 附录E E.2「四凹槽」；E.2.6 慢轴「定这个人本来的规格」 | L2b 壅而 γ 基线平（痰湿底） |
| **Ln 定位** | 病变**落在哪一层**（含 L2a／L2b／L2c 层内细分） | 主文档 D3（L1·微观／L2·中观／L3·宏观／L4·整体·系统） | L2b（脂质组／体水分分布） |
| **矛盾度定性** | 偏离稳态之**程度**——四级 | 主文档 8.5.1 Maod 四级：**稳态／轻度／中度／重度** | 中度 |

**三元合读为一象，例**：`L2b 壅而 γ 平（痰湿底）＋ 中度` —— 中医读作「痰湿内蕴（证）＋ 痰湿质（体）」，西医读作「高脂血症（定性）＋ 靶在脂代谢（定位）」。**同一象、两体系表述**。

**方人一层另加**：象定之后，其**方人**以「主凹槽＋惯用方 V」记（附录E E.3.4／E.4.2），如 `小青龙人 ＝ L1 过闭＋L2a 壅 ＋ V=[0.28, −0.05, {1+6}, {L1-L2}]`。

**三元之内部关系（要紧）**：三元不是三个并列标签，而是**一体三面**——**慢轴规格（体）＋ 空间定位（层）＋ 程度分级（量）**。三者**正交**、不互相加减（附录E E.6.3 同一纪律）：阴刻写「这人本来的规格」，Ln 写「当下病在何处」，Maod 写「偏离多远」。故「同为 L2b 壅滞」，γ 基线平者为痰湿、偏高者为湿热（附录E E.5.3）——**位置同而规格不同，即两象**，此即三元必须分写而不能合并为一的自证。

**与旧稿「三元书写」之衔接（登记）**：旧稿的三元书写在本表内**保留并深化**——它正是 QA-GPS 域内对应里「中医≈体质＋证」一句的**展开**；升级稿中三元书写即 **G 域内码本**的中医实例化。

## 三、约束来源（出 A 之前）

出 A 不是单看象，是**象＋三族约束同参**之下的一次选择：

| 层 | 约束 | 内容 | 篇内之位 |
|---|---|---|---|
| **内容侧·三族** | 证据族 | 指南、规范、共识、药品说明书 | 入候选（外借之知识源） |
| | 经验族 | 医者个体经验、师承、既往成败 | **主体面**工级之刻度 |
| | 处境族 | 患者经济承受、配合度、就医半径、家庭支持、共病 | 约束集之分量（资源／授权／主体面） |
| **资格侧·五约束集** | 候选／适配／资源／授权／主体面 | 哪一项为空即「不可选」，据以定落点与补哪一集 | 卷三 §3.6 |

**主体侧工级**：**上工／中工／下工**（《灵枢·邪气藏府病形》「上工十全九、中工十全七、下工十全六」）。

**工级之别不在「快慢」，而在「视野与空间」（v0.1 更正）**：旧映射表作「专家比新手更快达到收敛」——**判为不确**。同一批相、同一约束之下，工级之差见四处：

| 处 | 上工 | 下工 | 篇内之据 |
|---|---|---|---|
| **视野之高远** | **看得高、看得远**——所看之层高（Ln↑）、所及之时远（前瞻窗长） | 层低、窗短 | 主文档 D3 Ln |
| **候选象集之大小** | 能辨之别多，候选（Ω 之势）大 | 候选少 | 卷三 §3.6 多候选 |
| **颗粒度之细粗** | 细 | 粗 | 卷三 §3.6 主体面·分辨率 |
| **覆盖之广狭** | 广（所顾之维度多） | 狭 | 卷三 §3.5 覆盖率口径 |

**落到 A 同理**——候选策集亦更大、颗粒度更细、覆盖更广。「**治未病**」是一种**结果显象形式**：它不是另立的一项能力，而是**视野之高远**在结果上的显象——能于病未成形时即干预（「未病」即尚未显形之象，**能治未病 ＝ 能对未显形之象作业**）。故「治未病」与「看得高看得远」是一件事的两面：后者为因、前者为果。**追补（同日·再更正）**：上工**可以表现为**治未病，**不代表不能做中工、下工之事**——工级是**能力之包含**（上工 ⊃ 中工 ⊃ 下工），上工业务能力**更强**；**治未病只是其显现之一，非其定义**。**经文之留白须读出**（所举为高端显象，未举者非无——**举高以概全**），不可读作「上工只会治未病」。（已落 `Gn辨证论治篇 v1.9` 卷三 §3.6 之「工级之读法追补」与 §3.5.6 之「留白之三用」。）

**失效域**：经验族只在**高正则且反馈可及**处成立（Kahneman 与 Klein 2009），低正则或反馈迟浊处须退回证据族与处境族。

**出 A 之三段**：**聚合**（象 ＋ 指南〔G 借阅〕＋ 主体诉求） → **约束**（三族＋五约束集下之候选策集） → **选择**（满意解，非最优）。**策条件于象**——象定则措施空间定，象误则策无所依（「辨证错则施治无从对」）；**失效域**：对症支持一类，措施空间不随辨证而变，链序刚性在该处退为并行。

## 四、「相」在本链中的地位

本例之**原始材料（毛料）——四诊所得、化验单、影像等——本已在链中**（Q₀ 的首份材料与 S 的三形态）。既如此，**「相」作为一层独立命名，在本链内不重要**：S 只作**采集动作**、其产物＝数据集合，径称**采集／数据集合**即可（与 `QA-GPS` 于 QPOG 2.1／R12 之「相退役」同向）。

**登记（v0.1 再更正·同日）**：作者已裁定**篇名去「相」**——`Gn相与象篇` **改称《Gn 辨证论治篇》**（v1.8），「相」退为**采集侧之旧名**（语源注与历史名注保留，金句「相止于目接，象能由外推内」留作概念史路标），链内主称用**采集／数据集合**。此与本件方向一致——**本项自「待议」转「已裁」**。
