# Gn 医学体系 v4.1 · 内容汇总

> **版本**：v4.1（2026-09-10）。v4.1 对齐内核 v2.5 / 医学体系 v6.6：四层正式名更新为 L1·微观 / L2·中观 / L3·宏观 / L4·整体·系统，层内细分记号 Ln（n 取整数/1位小数/2位小数）。
>
> **方法说明**：本汇总用三步法提炼 Gn 体系——  
> ① **内核-封装拆除**：穿透全部表述层，拆除中医外壳与工程语言的外封装，暴露底层硬核内容；  
> ② **牛顿-欧几里得搭架**：像牛顿从少量公理推导力学大厦、欧几里得从五条公设搭建几何学那样，还原本体系从 1 条公理到 74 条定理再到临床应用的完整推导链；  
> ③ **门捷列夫补空位**：识别体系中已建立的概念格位与尚未填入的空缺格位，明确哪些位已满、哪些位待补。

## 第一层：内核-封装拆除

### 1.1 拆除中医外壳，露出什么？

| 传统中医表述 | 封装内芯（工程语言） | 本质一致性的底层内核 |
|-------------|-------------------|-------------------|
| **天人合一** | 开放系统与外部环境的持续物质-能量-信息交换 | 系统有序结构依赖外部负熵输入 |
| **阴阳** | 物质载体（M）与功能流（F）的双向耦合 | 二元组分互为依存，不可分割 |
| **表→半表半里→里→根** | L1-L2-L3-L4 四层递阶架构（L1·微观/L2·中观/L3·宏观/L4·整体·系统） | 开放复杂巨系统的最优分层 = 4 |
| **辨证** | 矛盾度 D2 的分层定性评估（4级×10维度） | 系统状态偏离稳态基准的量化指标 |
| **治法** | 四维偏性特征向量 V=[β,γ,{δ},{L}] | 对干预手段的四维统一标定 |
| **望闻问切** | 取象/建模——从高维混沌中提取关键特征的降维过程 | 取象与建模是同一认知动作的两套语言 |
| **六经传变** | 6 节点网状拓扑 MoE 架构，专家间流转权重矩阵 | 系统状态在六相位间的演化路径 |
| **卫气营血** | 4 层核心专家 + 3 个三焦子专家，分层递进式 MoE | 系统在高亢扰动下的四阶段线性演化 |
| **君臣佐使** | 涌现函数中的功能分工：主方向（60%）、增强（30%）、制衡（20%）、通达（10%） | 复方非线性协同效应的工程化分解 |
| **五行生克** | 5 节点闭环调控网络——生=协同，克=制约 | 满足生克闭环的最小拓扑 = 5 节点 |
| **取象/建模** | 特征工程——决定"什么值得被看见" | 不存在独立的"数据采集→建模"两步，取象即建模 |
| **MoE 架构** | 中医师"稀疏激活少量相关知识模块"的认知过程 | 象思维与稀疏激活大模型架构的原生同构 |

**拆除后暴露的统一底层**：所有中医概念的工程内核，都可以被同一套"系统科学+信息论+控制论+热力学"的公理语言统一描述。本体系做的事情就是：把中医从"经验直觉语言"翻译为"工程公理语言"。

### 1.2 拆除工程语言，露出什么？

| 工程化表述 | 封装内芯（认知本体论） | 底层认知内核 |
|-----------|---------------------|-------------|
| **特征工程/降维** | 取象——主动选择"看什么、不看什么" | 认知的本质就是选择性提取 |
| **Baseline Comparison** | 比对——将当前"象"与基准参照对比 | 判断偏离方向和程度 |
| **Model Fitting/迭代** | 矫正——基于比对结果修正认知框架 | 修正"看什么"的选择策略 |
| **交叉验证/测试集** | 多轮复诊——在反馈中校准取象准确度 | 检验模型/取象准确度的反馈机制 |
| **稀疏激活（MoE）** | 专家级直觉涌现——从串行推理变为并行直觉 | 人类高效认知的核心机制 |
| **涌现效应** | 君臣佐使协同——整体≠部分之和 | 系统论第一原理 |
| **负反馈闭环** | 自我调节/稳态维持——慢性病=负反馈渐进失效 | 系统健康的底层机制 |

**拆除后暴露的认知本体**：取象-比对-矫正不是"工程方法"，而是人类认知的原生结构。工程方法只是将这一原生结构显性化、可操作化。

### 2.1 欧几里得层：唯一公理 → 全部定理

**公理层（零起点）**

```
A0 · 三才耦合公理（唯一元公理）
"人体必然且持续地与天、地系统发生物质-能量-信息的双向耦合交换"
```

**推论层（A0 的自然展开，非独立公理）**

```
A0 ──→ 推论一：M/F 二元结构（任何系统均由物质载体+功能流构成）
A0 ──→ 推论二：四层递阶结构（最优分层 = 4）
A0 ──→ 推论三：矛盾度原理（健康=低矛盾动态平衡）
A0 ──→ 推论四：治则二分原理（顺治 vs 逆治）
```

**定理层（1+4 → 74条定理）**

```
A0 + 推论 ──→ S 系列（系统论定理 24 条）
           ──→ I 系列（信息论定理 14 条）
           ──→ C 系列（控制论定理 22 条）

```

**代表定理及其推导链（5 个已完整证明）**

| 定理 | 核心命题 | 推导依据 | 临床推论 |
|------|---------|---------|---------|
| **S1·整体涌现** | 系统整体 > 部分之和 | A0 + 推论一 | 复方效力不等于单药加和 |
| **S2·层次递阶** | 系统功能按层级组织，不可互相还原 | 推论二 | 传变遵循 L1→L4 层级规律 |
| **S4·负反馈稳态** | 健康通过负反馈维持，失效则病态 | 推论一 + 推论二 | 慢性病=负反馈渐进失效（L2 壅滞） |
| **S5·正反馈失控** | 恶化伴随正反馈环形成 | 推论一 + 推论三 | 急危重症=打破正反馈环（逆治截断） |

### 2.3 取象-比对-矫正：统一认知方法论

传统"取象→比对→建模"三步修正为：

```
取象/建模（同一动作的两套语言）
    │
    ▼
比对（与基准参照对比，判断偏离方向和程度）
    │
    ▼
矫正/迭代（修正认知框架，形成可复现的知识模型）
```

**核心洞察**：取象即建模——不存在独立的"数据采集→建模"两步流程。中医师做望闻问切时，不是被动接收信息，而是用已有认知框架主动筛选信息；数据科学家做特征工程时，不是预处理数据，而是决定世界的哪些维度值得被模型看见。
